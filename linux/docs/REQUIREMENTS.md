# AIHub Studio Linux — функциональные требования

## Цель
Единое desktop-приложение для облачных AI-сайтов и локальных LLM на Arch Linux / CachyOS.

## В первую очередь реализуем
- Electron с встроенным Chromium.
- React-интерфейс.
- Единый каталог Cloud Site и Local AI.
- Категории и отдельную системную категорию Favorites.
- Контекстные действия Add / Change / Del прямо в боковой панели.
- Веб-сайты во встроенных браузерных вкладках с отдельными профилями.
- Локальные LLM через OpenAI-compatible API.
- Автоматическое обнаружение моделей.
- Глобальная настройка HTTP / HTTPS / SOCKS4 / SOCKS5 proxy для Chromium-профилей.
- Пустое значение прокси означает использование системных настроек.
- Установку и запуск на Arch Linux / CachyOS через нативный pacman-пакет.

## Local AI — начальный профиль
Форма: Local AI → Add → Local AI.

| Поле | Начальное значение |
|---|---|
| Name | Local LLM |
| API type | openai |
| Host | localhost |
| Port | 11434 |
| Category | Local AI |
| Models | Automatic discovery |

Адрес по умолчанию: http://localhost:11434.

Адрес и порт задаются отдельно в форме подключения. Пользователь может их изменить. Приложение проверяет доступность endpoint и автоматически получает список моделей через поддерживаемый OpenAI-compatible API. Модель выбирается из обнаруженного списка. Модели обнаруживаются при открытии Local AI или вручную кнопкой обновления. Общение выполняется через /v1/chat/completions. История сообщений пока хранится только в оперативной памяти renderer и очищается при закрытии приложения; постоянный архив не реализуется.

Порт 11434 не означает, что любой endpoint обязательно является Ollama: базовый режим профиля — OpenAI-compatible.

## Категории и каталог
- Категории создаются, переименовываются и удаляются.
- Категории можно переставлять и назначать элементам каталога.
- Favorites — отдельная системная категория.
- Cloud Site добавляется по URL.
- Local AI добавляется через форму endpoint.
- Контекстное меню категорий и элементов содержит Add, Change, Del.
- Удаление категории не удаляет её подключения автоматически.
- Удаление подключения требует подтверждения.

## Общая рабочая область
Cloud Site использует Chromium, Local AI — API-клиент. Они отображаются в едином каталоге и открываются в центральной рабочей области приложения. Транспорт и внутренние обработчики остаются раздельными.
