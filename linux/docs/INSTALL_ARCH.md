# Arch Linux / CachyOS installation and development

## Target

- Arch Linux x86_64
- CachyOS x86_64
- KDE Plasma, GNOME or another desktop environment
- Wayland or X11

## Runtime dependencies

The generated pacman package declares Electron runtime dependencies:
- gtk3
- libnotify
- nss
- libxss
- libxtst
- xdg-utils
- at-spi2-core
- libsecret

The application bundles its own Electron/Chromium runtime. A separate system Chromium installation is not required.

## Install a release package

After downloading the generated .pacman artifact:

    sudo pacman -U ./AIHub-Studio-0.1.0-x64.pacman

The exact artifact filename is generated by electron-builder and may include an architecture suffix. Substitute the actual downloaded filename.

Start AIHub Studio from the desktop application launcher or:

    aihub-studio

Run the application as the regular desktop user. Do not run Electron with sudo.

## Build the Arch package from source

Install Node.js 24 and npm, then from this directory:

    npm install
    npm run package:pacman

The package is written to release/.

## Verify the build

    npm test
    npm run typecheck
    npm run build
    npm run smoke
    npm run package:pacman

The CI pipeline additionally installs the generated package into a clean Arch Linux container and checks the package metadata, desktop entry and installed executable.

## Desktop runtime validation

CI verifies a clean Arch package installation, but does not prove full desktop integration. The first CachyOS user test must confirm:
- application launches from KDE Plasma launcher;
- the window is grouped under the correct application icon;
- Chromium works in Wayland and X11 sessions;
- the user profile and site cookies survive a restart;
- the global proxy works with a reachable test proxy;
- local AI requests work against a user-configured OpenAI-compatible endpoint.

The pacman target in electron-builder is currently documented as beta, so test the generated package on the target distribution before broad distribution.
