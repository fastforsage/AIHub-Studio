# AIHub Studio — документация (RU)

**Версия документации:** Alpha 0.1.10  
**Статус продукта:** предварительная альфа-версия

AIHub Studio — настольная рабочая среда на Electron и встроенном Chromium для доступа к веб-сервисам искусственного интеллекта и локальным моделям с OpenAI-совместимым API.

## Возможности альфа-версии

- Постоянный каталог AI-провайдеров в левой панели.
- Раскрываемые категории и список избранного.
- Добавление, изменение и удаление категорий и провайдеров.
- Открытие веб-провайдеров во вкладках единого рабочего окна.
- Общий профиль Chromium с сохранением сессий и cookies.
- Подключение локальных OpenAI-совместимых API.
- Автоматическое получение списка моделей через `/v1/models`.
- Отправка запросов к локальным моделям через `/v1/chat/completions`.
- Настройка HTTP, HTTPS, SOCKS4 и SOCKS5 proxy.
- Просмотр диагностики и журналов приложения.
- Проверка доступности сервисов из каталога.

Состав каталога может изменяться. Наличие провайдера в каталоге не означает партнёрство, одобрение или официальную интеграцию с его владельцем.

## Установка в Windows

1. Скачайте MSI из раздела Artifacts соответствующего GitHub Actions workflow или из опубликованного Alpha Release.
2. Запустите установщик от имени пользователя с правами, необходимыми для установки приложения.
3. Следуйте инструкциям Windows Installer.
4. Запустите **AIHub Studio** из меню «Пуск».

Альфа-сборка предназначена для Windows 10/11 x64. Сборка MSI создаётся в CI на Windows runner с использованием WiX Toolset 5.0.2.

## Первый запуск

1. Откройте нужную категорию в левой панели.
2. Выберите AI-сайт, чтобы открыть его во вкладке.
3. Войдите на сайт непосредственно через его официальную страницу. AIHub Studio не предоставляет учётные записи провайдеров.
4. Для локальной модели добавьте Local AI с адресом OpenAI-совместимого API и портом сервера.
5. При необходимости задайте proxy в настройках.
6. Для диагностики используйте встроенный просмотр журналов.

Сессии и cookies веб-сайтов хранятся в профиле Chromium приложения. Не используйте общий профиль Windows для передачи приложения другим людям.

## Локальные данные и пути хранения

В Windows используются следующие каталоги:

- Настройки и каталог провайдеров: `%APPDATA%\AIHubStudio`
- Данные Chromium и сессии: `%LOCALAPPDATA%\AIHubStudio\Data`
- Журналы: `%LOCALAPPDATA%\AIHubStudio\Logs`

Не удаляйте эти каталоги, пока не сделали резервную копию нужных настроек. Удаление данных профиля может привести к потере локальных сессий и cookies.

В Linux используются XDG-каталоги пользователя:

- `$XDG_CONFIG_HOME/AIHubStudio` (по умолчанию `~/.config/AIHubStudio`)
- `$XDG_DATA_HOME/AIHubStudio` (по умолчанию `~/.local/share/AIHubStudio`)
- `$XDG_STATE_HOME/AIHubStudio` (по умолчанию `~/.local/state/AIHubStudio`)

## Конфиденциальность и обработка данных

AIHub Studio является клиентской оболочкой для веб-сайтов и локальных API. При открытии сайта браузерный компонент взаимодействует с соответствующим провайдером напрямую. Провайдер может получать IP-адрес, cookies, заголовки браузера, содержимое введённых запросов, загружаемые файлы и иные данные в соответствии со своей политикой и настройками.

Локальные настройки, профиль браузера, cookies и журналы хранятся на устройстве пользователя в указанных выше каталогах. Пользователь должен самостоятельно ознакомиться с содержимым журналов перед их передачей третьим лицам: журналы могут содержать URL, диагностические сведения и другие потенциально чувствительные данные.

**В текущей альфа-версии не заявлены функции автоматического архивирования истории разговоров, извлечения вложений или централизованного сбора содержимого чатов.** Не считайте наличие веб-вкладок функцией архивирования или резервного копирования переписки.

## Ограничения альфа-версии

Альфа-версия предназначена для тестирования. Возможны ошибки, изменения интерфейса и несовместимость отдельных сайтов. На данный момент не следует считать реализованными:

- автоматический сбор и архивирование переписки;
- SQLite-архив чатов и дедупликацию сообщений;
- извлечение и экспорт вложений;
- интеграцию Dockhand;
- удалённый мониторинг AMD MI50/GPU;
- централизованное управление облачными моделями через единый API.

Не храните единственную копию важных данных в тестовом профиле приложения.

## Сообщение об ошибках

При создании issue укажите версию приложения, ОС, шаги воспроизведения и ожидаемое/фактическое поведение. Перед публикацией журналов удалите cookies, токены, пароли, приватные URL, персональные данные и содержимое переписки.
